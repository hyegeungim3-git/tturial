# 뜨리얼 · Knit real

상상은 자유롭게, 한코한코 나답게!

대화로 뜨개 디자인을 바꾸고, 치수와 게이지에 맞춘 도안 및 제작 진도를 살펴보는 체험용 웹앱입니다.

**[뜨리얼 바로 사용하기](https://hyegeungim3-git.github.io/tturial/)**

## 체험하기

- 디자인 대화와 수정안 확인·적용
- 도안 번호·치수·배색과 연결된 2D SVG 예상도, 치수 마네킹에 입힌 도안 연동 360도 3D(니트 결·래글런·고무단) 및 고정된 실사 착용 참고 이미지
- 입력 게이지의 조직 도식과 직접 촬영한 실물 편물 견본 사진 확대
- 착용자 치수와 재료·세탁 전후 게이지 보관함
- 코·단 계산, 소매 이어뜨기, 실측에 따른 남은 도안 보정
- 작품별 버전 비교·복원, 진도 기록, 도안 인쇄
- 설정에서 작업 기록 JSON 내보내기·불러오기

## 데이터 저장

작품과 입력 기록은 사용 중인 브라우저에 저장됩니다. 계정 로그인과 기기 간 자동 동기화는 제공하지 않습니다. 다른 기기나 주소로 옮길 때는 설정에서 기록을 내보낸 후 새 주소에서 불러오세요.

## 프로토타입 안내

대화는 규칙 기반으로 작동합니다. 360도 3D는 네 가지 치수로 조형한 공통 마네킹에 설계 치수(가슴둘레·총장·단별 소매 둘레)의 스웨터를 입힌 형태 확인용이며, 주름·늘어짐은 규칙 기반 표현이고 실제 물성이나 핏을 시뮬레이션하지 않습니다. 2D SVG 예상도와 조직 도식은 입력한 치수·게이지·배색에서 그리며 실제 실의 물성이나 완성 핏을 예측하지 않습니다. AI 기본 이미지와 실사 착용 컷은 미리 만든 고정 참고 이미지로, 착용자 치수와 손땀 게이지를 반영하지 않습니다. 실물 편물 사진은 재료 보관함에 직접 추가할 수 있으며 현재 작품에 적용한 사진만 조직 보기에서 표시합니다. 도안 초안은 시험 제작으로 검증된 완성 도안이 아닙니다.

이 저장소는 웹앱의 공개 배포 파일입니다. GitHub Pages가 main 브랜치의 루트 폴더를 게시합니다. 로컬에서 확인하려면 이 폴더에서 `python -m http.server 4173`을 실행하고 `http://localhost:4173/`을 여세요.

Three.js와 Pretendard의 라이선스는 각각 `assets/THREE-LICENSE.txt`, `assets/fonts/OFL.txt`에 포함되어 있습니다.
