# 뜨리얼 · Knit real

상상은 자유롭게, 한코한코 나답게!

대화로 뜨개 디자인을 바꾸고, 치수와 게이지에 맞춘 도안 및 제작 진도를 살펴보는 체험용 웹앱입니다.

**[뜨리얼 바로 사용하기](https://hyegeungim3-git.github.io/tturial/)**

## 체험하기

- 디자인 대화와 수정안 확인·적용
- 도안과 연결된 360도 형태 및 실사 착용 참고 이미지
- 착용자 치수와 재료·세탁 전후 게이지 보관함
- 코·단 계산, 소매 이어뜨기, 실측에 따른 남은 도안 보정
- 작품별 버전 비교·복원, 진도 기록, 도안 인쇄
- 설정에서 작업 기록 JSON 내보내기·불러오기

## 데이터 저장

작품과 입력 기록은 사용 중인 브라우저에 저장됩니다. 계정 로그인과 기기 간 자동 동기화는 제공하지 않습니다. 다른 기기나 주소로 옮길 때는 설정에서 기록을 내보낸 후 새 주소에서 불러오세요.

## 프로토타입 안내

대화는 규칙 기반으로 작동하며, 실사 착용 이미지는 미리 생성한 참고 이미지입니다. 치수 기반 3D 형태와 도안 초안은 기능 시연용이며 실제 시험 제작으로 검증된 완성 도안은 아닙니다.

이 저장소는 웹앱의 공개 배포 파일입니다. GitHub Pages가 main 브랜치의 루트 폴더를 게시합니다. 로컬에서 확인하려면 이 폴더에서 `python -m http.server 4173`을 실행하고 `http://localhost:4173/`을 여세요.

Three.js와 Pretendard의 라이선스는 각각 `assets/THREE-LICENSE.txt`, `assets/fonts/OFL.txt`에 포함되어 있습니다.
